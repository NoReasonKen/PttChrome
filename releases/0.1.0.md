PttChrome Fork Android 0.1.0

## Highlights

- Install PttChrome Fork independently alongside the upstream Android app.
- Open article images in a viewer with pinch zoom, double-tap zoom, and swipe navigation.
- Adapt inline previews to the available height and return to the viewed image when closing the viewer.
- Support Google preference sync for approved accounts.
- Improve reading-position restoration when images expand and articles reopen.
