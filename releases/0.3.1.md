PttChrome Fork Android 0.3.1

## Highlights

- Choose local encrypted storage or a password manager for Android automatic login, with one explicit save form and confirmed local credential deletion.
- After upgrading, manually save credentials to the selected method. Legacy plaintext is no longer used for automatic login and is cleared automatically only after successful local encrypted enrollment.
- Manage and pin search history in Settings, with automatic pinning for frequently used terms. Old search history is not migrated to the new format; previous external-search settings must be entered again.
- Refine the article App Bar author, board and time layout, and balance spacing around mobile comment-card separators.
- Restore diagnostic login sends after reconnecting while protecting credentials in recordings, settings exports and synchronization.
- Fix occasional Back navigation from some search results returning to the full article list instead of the source article.
