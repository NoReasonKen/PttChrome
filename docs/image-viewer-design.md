# Image Viewer Integration

This records why the image viewer is integrated the way it is and how it connects to PttChrome's reading screen. The implementation uses PhotoSwipe **5.4.4**, whose core accepts an image data source without a React gallery and appends its dialog outside the article. That fits the existing plain DOM screen and avoids adding another React island. [PhotoSwipe 5.4.4 release](https://github.com/dimsemenov/PhotoSwipe/releases/tag/v5.4.4), [package exports](https://github.com/dimsemenov/PhotoSwipe/blob/v5.4.4/package.json), [MIT license](https://github.com/dimsemenov/PhotoSwipe/blob/v5.4.4/LICENSE), [data sources](https://photoswipe.com/data-sources/).

## Reading-screen boundary

`ScreenController` owns activation of a successfully loaded inline image. It dispatches the selected image URL, intrinsic dimensions, alt text, referrer policy, and trigger element to the application-owned `ImageViewer`. The viewer presents one image without moving the inline preview or changing the article's layout. Passing the loaded URL preserves the selected source candidate and avoids repeating host resolution. The PhotoSwipe image-load event copies the original referrer policy to its image element. [Screen activation](../src/render/screen.js), [viewer adapter](../src/js/image_viewer.js), [PhotoSwipe image loading](https://github.com/dimsemenov/PhotoSwipe/blob/v5.4.4/src/js/slide/content.js).

The inline preview remains capped at `23.75em` high and `39em` wide. The viewer starts at PhotoSwipe's `fit` level, which fits the full image in the viewport without enlarging it beyond natural size. Double-tap toggles to exactly `fit * 2` and back to fit. Its maximum is `max(fit * 8, viewportWidth / naturalWidth * 2)`: the second term also lets a small or very tall image reach at least twice the viewport width. This is an explicit product limit; it can enlarge beyond both natural size and the viewport. Pinch continues from the current zoom and panning follows PhotoSwipe's bounds. [PhotoSwipe zoom options](https://photoswipe.com/adjusting-zoom-level/), [versioned zoom calculation](https://github.com/dimsemenov/PhotoSwipe/blob/v5.4.4/src/js/slide/zoom-level.js), [gesture behavior](https://github.com/dimsemenov/PhotoSwipe/blob/v5.4.4/src/js/gestures/zoom-handler.js).

## Modal and close lifecycle

`App` owns the viewer and registers its close action with the existing sheet-dismissal priority, which connects Android system Back to the same close path. The viewer also closes when the article changes or the terminal settles on a different screen type, when the connection closes, or through its visible Close button and Escape. `setModalOpen('imageViewer', ...)` gates terminal input; while open, the viewer marks the rest of the document inert. The adapter restores prior inert values, unregisters dismissal, releases the modal gate, and returns focus to the triggering image if it remains connected. [Application lifecycle and modal gate](../src/js/pttchrome.jsx), [viewer lifecycle](../src/js/image_viewer.js), [PhotoSwipe options](https://photoswipe.com/options/), [events](https://photoswipe.com/events/).

The adapter keeps PhotoSwipe-specific options in `src/js/image_viewer.js`. PhotoSwipe supplies gesture recognition, zoom levels, panning, focus containment, and Escape handling; PttChrome supplies the reading-screen event, modal ownership, system-back integration, and trigger focus restoration. This division keeps touch behavior in the image viewer and screen ownership in the application.

Keep the modal gate active until PhotoSwipe emits `destroy`: even with opening/closing animations disabled, `close()` can complete on a later timer. The adapter reports `imageviewerchange` on `window`; the history guard uses this lifetime to close the viewer before terminal navigation. When terminal Back mapping is disabled, it creates and retires only the temporary viewer history entry. A Back-triggered close must not restore that entry while destruction is pending. Programmatic history cleanup also mutes deep-link consumption through the existing self-navigation scope. [Viewer lifecycle](../src/js/image_viewer.js), [history ownership](../src/js/history_back_guard.js), [asynchronous close regression](../tests/unit/history_back_guard.test.js).
